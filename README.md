# Gran Cookies

Site estático pronto para GitHub Pages.

- `index.html` → página
- `style.css` → visual
- `script.js` → funcionamento
- `cardapio.js` → **edite este arquivo para mudar sabores, preços, estoque e WhatsApp**

## GitHub Pages
1. Crie um repositório.
2. Envie estes arquivos para a raiz.
3. Settings → Pages → Deploy from a branch.
4. Selecione `main` e `/ (root)`.
5. Salve.

## Fotos dos cookies
- Coloque as fotos dentro da pasta `imagens/`.
- No `cardapio.js`, preencha `imagem: "imagens/nome-do-arquivo.jpg"` no sabor correspondente.
- Cada sabor tem seu próprio campo `imagem`. Se estiver vazio, aparece um ícone provisório.
- Use nomes simples, sem espaços, e confira a extensão (`.jpg`, `.png` etc.).
